## 🌐 Hướng dẫn Triển khai (Deployment Guide)

### Triển khai trên Vercel / Netlify / Cloudflare Pages:
1. Push toàn bộ thư mục này lên GitHub cá nhân `https://github.com/HoangKhoi1704/HoangKhoi1704`.
2. Truy cập [Vercel Dashboard](https://vercel.com/) -> Chọn **Import Git Repository**.
3. Giữ nguyên đường dẫn root (`/`) và nhấn **Deploy**.
4. Website sẽ trực tiếp vận hành tại tên miền cá nhân của bạn!
